# odin-recipes

This project is the very first hands-on project in The Odin Project Foundations curriculum. 
The goal is to build a basic recipe website to practice HTML basics and get comfortable with Git/GitHub.

## Recipes on the site

For now, here is what you can prepare:

- **Tiramisu**
- **Chocolate Mousse**
- **Panna Cotta**

## Skills practiced

- Basic web page structure (HTML Boilerplate)
- Headings, paragraphs, and lists (ordered and unordered)
- Embedding images and linking pages using relative paths
- Full Git workflow (add, commit, push, managing ".gitignore")
